# web-absensi

Sistem absensi sekolah sederhana dengan 3 tampilan:
- Admin
- Guru/Dosen
- Siswa/User

## Struktur proyek

- `backend/` - API Express sederhana dengan data in-memory
- `frontend/` - React + Vite UI untuk login dan dashboard

## Cara menjalankan

1. Jalankan `npm install` di folder root
2. Jalankan `npm run dev`
3. Buka `http://localhost:5173` untuk frontend
4. Backend berjalan di `http://localhost:4000`

## Login contoh

- Admin: `admin@sekolah.local` / `admin123`
- Guru: `teacher@sekolah.local` / `guru123`
- Siswa: `student@sekolah.local` / `siswa123`
